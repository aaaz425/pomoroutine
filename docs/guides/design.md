# 디자인 시스템

- 타이머가 가장 눈에 띄고 나머지 화면은 뒤로 물러나도록 설계
- 기본은 다크 모드, 라이트 모드와 시스템 설정 따라가기도 지원
- 다크는 Linear, 라이트는 Cal.com의 디자인 시스템을 참고해 조정
- 웹과 앱은 같은 색과 폰트 값을 사용

## 1. 디자인 원칙

- 포인트 색은 한 화면에 하나만
- 그림자 없이 배경 밝기 차이로 층을 구분
- 포인트 색은 진행 링, 시작 버튼, 포커스 표시처럼 사용자가 지켜보거나 눌러야 하는 곳에만
- 집중 모드에서는 타이머와 동기부여 메시지만 남기고 모두 숨김
- 애니메이션은 상태가 바뀔 때만 사용하고, 타이머 뒤 빛 번짐 효과도 타이머가 돌 때만 움직임

## 2. 색상

### 컬러 테마

포인트 색은 설정에서 고른 컬러 테마를 따르고, 기본 테마는 미드나잇

| 테마 | 라이트 | 다크 |
|---|---|---|
| 미드나잇 | `#0aaa7d` | `#10d9a0` |
| 선셋 | `#ff8a4c` | `#ff8a4c` |
| 오션 | `#38bdf8` | `#38bdf8` |
| 모노 | `#27272a` | `#f4f4f5` |

- 미드나잇은 흰 배경에서도 잘 보이도록 라이트 모드에서 더 진한 민트 사용
- 모노는 라이트 모드에서 흰 배경에 묻히지 않도록 진한 회색 사용

### 배경과 텍스트

| 토큰 | 용도 | 라이트 | 다크 |
|---|---|---|---|
| background | 페이지 배경 | `#ffffff` | `#07090f` |
| card | 카드, 패널 | `#f8f9fa` | `#0d1117` |
| popover | 모달, 드롭다운 | `#f5f5f5` | `#111827` |
| muted | 비활성 영역, 보조 배경 | `#efefef` | `#1a2332` |
| border | 테두리, 구분선 | `#e5e7eb` | `#1e2d3d` |
| foreground | 기본 텍스트 | `#111111` | `#f0f4f8` |
| muted-foreground | 보조 텍스트 | `#374151` | `#94a3b8` |
| destructive | 삭제, 오류 | `#ef4444` | `#ef4444` |
| success | 성공 토스트 | `#22c55e` | `#22c55e` |
| info | 안내 토스트 | `#3b82f6` | `#3b82f6` |

### 타이머 상태 색

| 상태 | 색 |
|---|---|
| 집중 | 컬러 테마의 포인트 색 |
| 휴식 | `#60a5fa` |
| 대기, 일시정지 | 보조 텍스트 색 |

- 진행 링, 상태 뱃지, 뒤쪽 빛 번짐 효과가 모두 같은 색으로 바뀜
- 이 세 가지 외의 색은 타이머 주변에 쓰지 않음

## 3. 타이포그래피

| 용도 | 폰트 |
|---|---|
| 본문과 UI | Pretendard |
| 타이머 숫자 | Geist Mono |

- 한글과 영문이 한 폰트로 자연스럽게 섞이도록 Pretendard 사용
- 타이머 숫자는 초가 바뀔 때마다 글자 폭이 달라져 흔들리지 않도록 고정폭 폰트 사용
- 굵기는 400, 500, 600, 700 네 단계만 사용

## 4. 핵심 컴포넌트

**타이머 링**
- 원형 링 가운데에 남은 시간과 현재 상태 표시
- 링 크기는 화면 너비에 따라 180px, 220px, 240px
- 타이머 숫자도 같은 기준으로 28px, 40px, 48px
- 자유 모드는 끝나는 시간이 없어 링을 옅게 채워 두고 시간만 올라감

**사이클 점**
- 마친 사이클은 채운 점, 남은 사이클은 빈 점
- 지금 진행 중인 사이클은 깜빡이는 점

**카테고리 색**
- 프리셋 7색에 더해 컬러 피커로 원하는 색 선택 가능
- 카테고리 색은 뱃지와 차트에서만 쓰고 포인트 색 자리에는 쓰지 않음

## 5. 반응형

| 너비 | 레이아웃 |
|---|---|
| 640px 미만 | 한 단 구성, 하단 탭 바 |
| 640px에서 1024px | 한 단 구성, 아이콘 사이드바 |
| 1024px 이상 | 사이드바와 콘텐츠 |

## 6. 접근성

- 기기에서 동작 줄이기를 켜면 화면 전환 애니메이션 생략
- 차트마다 스크린리더용 데이터 표 제공
- 라이트 모드에서 포인트 색 글자는 흰 배경에서도 잘 읽히는 진한 값 사용
