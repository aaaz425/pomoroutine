## 1. 포모도로 타이머

집중과 휴식이 번갈아 진행되는 사이클 타이머 — 정한 사이클을 모두 마치거나 직접 종료하면 한 번의 기록이 끝남

**사용자 스토리**
- 수험생으로서 집중과 휴식 시간을 내 공부 방식에 맞게 정하고 싶음
- 다른 화면으로 이동해도 타이머가 계속 돌아가길 원함

**주요 동작**
- 시작 시 설정의 타이머 기본값으로 채워지고, 이번 타이머에 한해 시간과 사이클 조정 가능
- 집중 1–120분, 휴식 0–60분, 사이클 1–10회
- 시간 증감 버튼은 5분 단위, 직접 입력은 1분 단위
- 집중이 끝나면 휴식이, 휴식이 끝나면 다음 집중이 자동 시작
- 마지막 사이클이 끝나거나 종료 버튼을 누르면 기록 화면 표시
- 일시정지 후 재개하면 멈춘 시점부터 이어서 진행
- 백그라운드 탭에서도 시간이 밀리지 않고, 탭으로 돌아오면 즉시 다시 계산
- 다른 화면에서는 미니 타이머로 진행 상황 표시

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 실행 중 새로고침이나 앱 재시작 | 기기에 저장한 타이머 상태로 복원 |
| 진행 중 작업 변경 | 불가, 시작한 뒤에는 작업 고정 |
| 작업 없이 시작 | 미분류로 진행, 기록 화면에서 작업 지정 가능 |
| 진행 중 타이머 기본값 변경 | 현재 타이머는 그대로, 다음 타이머부터 반영 |
| 일시정지 상태로 오래 방치 | 이어서 할지 종료할지 묻는 안내 표시 |

## 2. 자유 모드

정해진 시간이나 사이클 없이 집중한 시간만 재는 스톱워치 모드

**사용자 스토리**
- 시간을 정하지 않고 자연스럽게 끝날 때까지 집중하고 싶음

**주요 동작**
- 타이머 시작 화면에서 포모도로와 자유 중 선택
- 0부터 시간이 올라가고 사이클 표시는 숨김
- 자동 종료와 알림음 없이 종료 버튼으로만 끝냄
- 기록과 저널에는 사이클 수 대신 집중 시간만 표시

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 집중 시간 상한 | 포모도로와 달리 경과 시간 전체를 집중 시간으로 인정 |
| 사이클 기반 뱃지 | 사이클이 없어 대상에서 제외 |

## 3. 집중 모드

타이머와 동기부여 메시지만 남기고 나머지 화면을 가리는 전체 화면 모드

**사용자 스토리**
- 집중하는 동안 다른 화면 요소에 눈이 가지 않길 원함
- 지칠 때 힘이 되는 문구를 보고 싶음

**주요 동작**
- 타이머가 실행 중일 때만 진입 가능
- 설정에서 관리하는 동기부여 메시지가 일정 간격으로 무작위 교체
- 나가도 타이머는 계속 진행
- 스페이스로 일시정지와 재개, ESC로 나가기

## 4. 작업 관리

무엇에 집중할지 정하는 기능 — 작업은 제목과 카테고리만 가지고, 타이머 시간은 작업과 무관하게 정함

**사용자 스토리**
- 오늘 할 일을 목록으로 정리하고 싶음
- 과목별로 카테고리를 붙여 나중에 과목별 시간을 보고 싶음
- 우선순위에 따라 순서를 바꾸고 싶음

**주요 동작**
- 제목 필수, 카테고리 선택
- 생성, 수정, 삭제, 드래그로 순서 변경
- 기본 카테고리 5개 제공, 사용자 카테고리 추가 가능
- 변경은 화면에 먼저 반영하고 저장 실패 시 되돌린 뒤 안내

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 공백만 입력 | 저장 버튼 비활성 |
| 작업이 쓰는 카테고리 삭제 | 삭제를 막고 안내 |
| 작업 삭제 | 해당 작업의 기록은 미분류로 유지 |

## 5. 회고 기록

타이머가 끝나면 집중한 내용을 짧게 돌아보고 남기는 기능

**사용자 스토리**
- 타이머가 끝나면 무엇을 했는지 짧게 적어두고 싶음
- 무엇이 집중을 방해했는지 기록해 패턴을 알고 싶음

**주요 동작**
- 종료 시 완료한 사이클, 집중 시간, 작업을 보여주는 기록 화면 표시
- 회고 메모 최대 500자, 선택 사항
- 집중도 3단계와 방해 요소 태그 선택, 둘 다 생략 가능
- 방해 요소는 기본 6종에 직접 입력 추가 가능
- 건너뛰기를 누르면 확인 후 기록을 남기지 않음

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 집중 30초 미만에서 종료 | 기록 없이 초기화하고 안내 |
| 저장 실패 | 입력한 내용을 유지한 채 다시 시도 가능 |

## 6. 저널과 인사이트

지난 기록을 목록과 캘린더로 보고, 집중도와 방해 요소를 바탕으로 패턴을 알려주는 화면

**사용자 스토리**
- 지난 기록을 다시 보고 잘못 남긴 내용을 고치고 싶음
- 날짜별로 꾸준히 했는지 한눈에 보고 싶음

**주요 동작**
- 목록은 날짜별로 묶어 최신순 표시, 검색과 카테고리, 기간 필터 제공
- 캘린더는 기록이 있는 날만 표시하고, 날짜를 누르면 그날 기록 목록 표시
- 기록 상세에서 제목, 작업, 메모, 집중도, 방해 요소를 한 번에 편집하고 저장
- 기록 삭제는 확인 후 진행
- 인사이트 4종
  - 최근 14일 방해 요소 상위 3개
  - 최근 7일과 그 전 7일의 집중도 비교
  - 카테고리별 평균 집중도
  - 집중도가 가장 낮은 요일

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 인사이트 표본 부족 | 항목별로 데이터가 부족하다는 안내 |
| 필터 결과 없음 | 검색 결과가 없다는 안내 |
| 캘린더의 미래 날짜나 기록 없는 날 | 선택 불가 |

---

## 7. 통계

쌓인 기록을 기간별로 모아 집중 패턴을 보여주는 화면

**사용자 스토리**
- 오늘 몇 시간 집중했는지 바로 보고 싶음
- 며칠 연속으로 했는지 보면서 흐름을 이어가고 싶음
- 어느 카테고리에 시간을 많이 썼는지 알고 싶음

**주요 동작**
- 오늘, 이번 주, 이번 달, 전체 탭
- 집중 시간, 기록 수, 연속 집중일, 기록당 평균을 직전 기간과 비교해 표시
- 구간별 카테고리 누적 막대 차트와 카테고리 비율 도넛 차트
- 시간대별 집중량 차트와 이번 달 히트맵
- 집중 시간은 일시정지를 뺀 실제 집중 시간만 집계

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 기록 없음 | 타이머 시작을 유도하는 빈 상태 |
| 미분류 기록 | 차트에 미분류로 표시 |
| 자정 전후 기록 | 사용자 시간대 기준으로 날짜 계산 |

## 8. 뱃지

따로 저장하지 않고 기록에서 매번 계산하는 성취 뱃지

**사용자 스토리**
- 조건을 채워 뱃지를 모으면서 꾸준히 기록할 동기를 얻고 싶음

**주요 동작**
- 획득한 뱃지만 기본 표시, 모두 보기로 미획득 뱃지까지 펼침
- 연속 기록 3, 7, 30, 100일
- 누적 시간 1, 10, 50, 100시간
- 카테고리 다양성 2, 3, 5, 7종
- 특별 뱃지 — 첫 기록, 심야 집중, 주말 집중, 퍼펙트 기록, 2시간 이상 마라톤
- 미획득 뱃지는 회색으로 표시하고 조건을 툴팁으로 안내

## 9. 공유 카드

선택한 기간의 집중 요약을 정사각형 이미지로 만들어 공유하는 기능

**사용자 스토리**
- 내 집중 기록을 SNS에 자랑하고 싶음

**주요 동작**
- 통계 화면의 현재 탭 기준으로 카드 생성
- 기간, 헤드라인, 총 집중 시간, 기록 수, 연속 기록, 생성일 표시
- 이미지 저장 지원, 파일 공유를 지원하는 환경에서만 공유 버튼 표시
- 별도 이미지 파일 없이 브라우저에서 직접 그림

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 기록 없는 기간 | 아직 기록이 없다는 헤드라인과 0분 표시 |
| 긴 집중 시간 문구 | 카드 폭에 맞춰 글자 크기 자동 축소 |
| 공유 중 취소 | 오류 없이 종료 |

## 10. 알림

타이머가 끝날 때 화면을 보고 있지 않아도 알 수 있게 하는 기능

**사용자 스토리**
- 다른 탭에서 일하다가도 타이머가 끝나면 알고 싶음

**주요 동작**
- 집중 종료, 휴식 종료, 전체 종료 시점에 알림
- 브라우저 알림과 소리 알림을 각각 켜고 끔
- 소리는 종류 4가지, 음량, 반복 횟수 설정 가능
- 앱은 기기 알림으로 전달

**엣지 케이스**

| 상황 | 처리 |
|---|---|
| 알림 권한 거부 | 브라우저 알림이 켜지지 않고 소리 알림만 동작 |
| 알림 미지원 브라우저 | 소리 알림만 동작 |

## 11. 설정

**사용자 스토리**
- 집중, 휴식, 사이클 기본값을 한 번 정해두고 매번 다시 맞추고 싶지 않음
- 집중 모드에서 볼 문구를 직접 쓰고 싶음

**주요 동작**
- 계정 — 닉네임, 비밀번호 변경, 로그아웃, 회원 탈퇴
- 타이머 기본값 — 바꾸면 대기 중인 타이머에 바로 반영
- 테마 — 라이트, 다크, 시스템과 컬러 테마 4종
- 작업과 카테고리 관리 — 카테고리 최대 10개, 색상 자유 선택
- 동기부여 메시지 — 추가, 수정, 삭제, 최소 1개 최대 20개
- 알림 — 브라우저 알림, 소리, 타이머 실행 중 화면 꺼짐 방지
- 앱 정보 — 버전, PWA 설치 안내
- 의견 보내기 — 최대 1000자, 하루 5번까지, 접수되면 운영자에게 메일 알림

## 12. 로그인과 비회원 체험

**사용자 스토리**
- 가입하기 전에 먼저 써보고 싶음
- 한 계정으로 웹과 앱의 기록을 이어서 보고 싶음

**주요 동작**
- 이메일 가입과 메일 인증, 비밀번호 재설정
- 카카오 로그인
- 가입 시 기본 카테고리와 기본 설정 자동 생성
- 비회원은 타이머만 사용, 종료 시 기록 대신 로그인 안내
- 비회원이 통계, 기록, 설정에 들어가면 로그인 안내
- 로그아웃 시 기기에 남은 타이머 상태도 삭제해 다음 계정에 노출되지 않게 함
- 로그아웃은 그 기기만 끊고 다른 기기의 로그인은 유지, 회원 탈퇴는 모든 기기에서 로그아웃
- 로그아웃 후에는 로그인 화면, 회원 탈퇴 후에는 웹은 랜딩, 앱은 로그인 화면으로 이동
- 로그인 화면에서 로그인 없이 타이머로 바로 이동 가능
- 앱 통계, 기록 탭에서 로그인이 만료됐으면 다시 로그인 안내
