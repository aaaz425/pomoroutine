# PRD

## 1. 요약

- 집중한 시간을 기록하고 분석해 꾸준히 이어가도록 돕는 포모도로 집중 도구
- 집중 타이머 → 회고 기록 → 통계 흐름을 한 앱에서 제공
- 쌓인 기록을 눈으로 확인하면서 꾸준히 다시 찾게 만드는 것이 목표

## 2. 문제 정의

**배경**
- SNS 알림과 추천 영상 등 주의를 빼앗는 환경에서도 수험생, 취업 준비생, 직장인은 할 일을 끝내야 함

**기존 타이머 앱의 한계**
- 집중한 기록이 남지 않거나 보이지 않아 동기부여가 이어지지 않음

**해결 방향**
- 집중, 기록, 분석을 하나의 흐름으로 연결
- 시간은 사용자가 정하고 언제든 일시정지와 종료 가능 — 타이머는 도구일 뿐 주도권은 사용자에게
- 누적 통계, 스트릭, 뱃지로 성취를 시각화

## 3. 타겟 사용자

| 사용자 | 핵심 니즈 |
|---|---|
| 수험생 | 과목별 공부 시간 추적, 스트릭 유지 |
| 취업 준비생 | 자기소개서와 포트폴리오 작업 시간 기록 |
| 자기계발 직장인 | 퇴근 후 사이드 프로젝트와 운동 집중 |
| 집중이 어려운 사람 | 짧은 사이클로 시작해 작은 성취부터 경험 |

## 5. 사용자 시나리오

**첫 방문**
- 타이머 화면으로 바로 진입
- 비회원으로 타이머 체험
- 기록을 남기려면 로그인하라는 안내를 보고 회원가입
- 타이머 시작, 작업 연결은 선택
- 집중 모드로 몰입
- 종료 후 회고 기록
- 통계에서 오늘 집중 시간 확인

**재방문**
- 로그인 유지 상태로 진입
- 타이머 시작
- 다른 화면에서도 미니 타이머로 진행 확인
- 통계에서 스트릭 확인

## 6. 제약과 가정

- 기록 저장은 로그인 필수, 오프라인 우선 구조 아님
- 두 기기에서 동시에 타이머를 실행하면 기록이 중복 저장될 수 있음 — 서버 잠금이 필요해 일단 보류
- 웹과 앱 UI는 동일하게 유지하고, 통계와 기록 화면은 웹을 WebView로 재사용

**타이머 기본값 근거**
- 집중 25분, 휴식 5분, 4사이클 — 프란체스코 시릴로의 포모도로 원안 기준, 사용자가 기본값 변경 가능
- 집중 상한 120분 — 울트라디안 리듬 주기 약 90분, Lavie 1986 참고
- 집중 하한 1분
- 휴식 하한 0분 — 쉬지 않고 이어가는 사이클 허용
- 사이클 상한 10회 — 기본값의 2.5배로, 하루에 한 번 길게 집중하는 경우까지 고려
